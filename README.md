# 内容生产工作台 Demo

一个可操作的新媒体内容生产流程：**选题分析 → 内容创作 → 人工审核 → 数据复盘**。适合向团队或客户演示 Agent 与 API 如何串联内容工作，同时保留人工决策。

## 启动

需要 Python 3.11+。推荐使用 `uv`：

```bash
uv sync
uv run streamlit run app.py
```

也可使用 `pip install -e .` 安装后运行 `streamlit run app.py`。浏览器打开终端显示的本地地址。

## 演示流程

1. 创建任务，使用预填的“青山咖啡”场景或输入自己的品牌信息。
2. 生成并选定一个选题。
3. 生成图文稿和短视频脚本。
4. 在审核页修改、退回或通过发布稿，并下载最终 JSON。
5. 上传 `sample_metrics.csv` 或直接输入数据，查看复盘和下一轮选题建议。

没有 API Key 时，页面会显示“演示数据”，使用本地模板生成内容。演示数据不会被描述成实时热点或真实平台数据。任务记录保存在本地 `content_demo.db`。

## 接入模型 API

在启动前设置 `OPENAI_API_KEY` 环境变量。可选设置 `OPENAI_MODEL`（默认 `gpt-4o-mini`）。设置后页面显示“AI API”，生成选题、成稿和复盘时调用 OpenAI Responses API。请勿把密钥写进代码或提交到 Git。

发布动作和平台数据 API 尚未接入；这两处目前分别使用下载发布稿和 CSV 导入。接入真实平台时，可替换这两个边界，不需要重做审核流程。
